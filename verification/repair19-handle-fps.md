# repair19：常驻白条与 FPS 图层遍历

用户要求已添加的 1DM+ 等应用中白条常驻、默认贴边、轻点展开，并继续修复 FPS。

白条取消十秒自动淡出，前台监测维持收起状态白条可见。默认内缩为 0；已有手动位置仍保留。短按通过 Android touch slop 和 300ms 门槛识别，调用原面板创建和展开动画。拖动、长按、多指和取消不会额外打开。离开已添加应用或锁屏仍按原流程隐藏；保留原设置和侧栏 UI。

FPS 发现阶段此前只轮询前八个匹配图层；容器较多时实际渲染图层可能永远漏查。现在每批两个图层，返回总数量，遍历全部完整包名匹配图层后循环，已有有效图层继续缓存采样，失效后重查。明确区分系统拒绝读取帧数据。继续仅使用 actualPresentTime；过期/空/待呈现数据不可用，不用屏幕刷新率或 gfxinfo 渲染次数冒充实际呈现帧率。

验证：77 项自动化检查（14 FPS 解析、6 前台、13 shell 模拟、14 坐标、12 轻点、18 设置模拟）及原 APK 反射/资源/接线静态检查通过。shell 模拟覆盖第九至十二个图层、缓存与转义。完整 Java/D8/apktool 构建、v1/v2/v3 签名、ZIP CRC、七 DEX 校验和 zipalign 通过。

版本 10.4.5-huawei-repair19-handle-fps / 40001058，沿用本会话新签名，可覆盖 repair18。没有手机或模拟器实测，不能保证 HarmonyOS 一定开放有效帧时间或已完全消除华为小窗冲突。用户截图显示原工具箱能在 1DM+ 上打开，但静止画面没有新帧不能证明采样通道可用。

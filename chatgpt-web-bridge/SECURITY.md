# 安全说明

会话 Cookie 使用 Secure、HttpOnly、SameSite=Strict 和主机限定前缀。Web Bridge 登录密码保存在独立账号目录中的 bcrypt 哈希文件。写接口验证 Origin 与会话 CSRF Token。WebSocket 同时验证会话和 Origin，只接入私有 Unix socket，单个控制连接随密码更改、登出或过期被关闭。登录和改密采用全局限速。

ChatGPT 官方认证在 Chromium 中进行。浏览器保留原有沙箱和独立持久化配置。项目没有 Chromium 调试端口。Bridge 传输远程画面和用户输入，应用日志采用固定消息。含账号数据的浏览器资料目录只对浏览器用户和 VPS 管理员可读，请将该目录与文件系统快照视为敏感数据。项目备份仅包含服务设置和密码哈希。

远程桌面属于高权限个人工具。持有 Bridge 密码的人能控制当前已登录的 Chromium、访问聊天记录和文件面板。使用独立强密码，只授权可信人员和可信设备。远程 Chromium 可以打开链接和系统文件对话框，应避免在同一 VPS 上把敏感资料设为全局可读，也可用 VPS 防火墙对该专用账号限制内网出口。浏览器服务和 Web 服务用独立账号，上传目录对浏览器只读，下载目录分组共享。文件接口只服务已授权的普通文件和安全文件名。

通过仓库的私密反馈渠道报告漏洞，避免在公开 Issue 粘贴密码、Cookie、聊天内容或生产日志。安全更新建议从受信任的发行版仓库或浏览器供应商获取。

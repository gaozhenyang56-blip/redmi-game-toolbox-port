# 千恋＊万花 WebAssembly 私有预览

生产预览18444，开发测试18445。用户已授权先发布预览，后续改动仅更新测试端口；完整剧情、中文和账号云存档的验证状态需据实际记录更新，不能把菜单截图当作通关验收。

本项目使用 KrKr2 Web 的公开发布构建（源提交2028cbccaa91498bd36f270d349ae711d0e8fed3）。原引擎版权与第三方声明在 engine/LICENSE.upstream.txt。浏览器外层移除统计请求、固定持久存档空间，16:9游戏视口适配手机横屏；支持JSPI的新版Chromium与可信HTTPS是运行条件。

游戏本体、成人资源、原生游戏可执行文件、用户提供的分享地址、下载签名、密码和存档均不进入Git。部署输入使用服务器专用RSA公钥/AES-GCM加密；站点为独立系统用户、独立服务、独立目录，不改变现有轻连和远控服务。两个端口当前使用独立私有访问凭据，凭据由服务器生成，仅私有交付。

资源转换只改XP3索引名称，保留数据段，算法布局参考MIT许可的GARbro YuzCrypt.cs/ArcXP3.cs。兼容脚本来源zeas2/Kirikiroid2_patch，仅用于基础游戏格式和图形兼容，不加载额外成人资源。

首次部署先生成传输公钥，再加入加密资源清单触发准备资源和启动服务。原RAR是恢复源；CPU/磁盘准备完成后才启动端口。后续更新只重启测试服务，发布预览指针保持不变。

账号和云存档模块尚在开发，不属于当前预览版已完成功能。

## 文件管理后台（测试端口）

`https://107.150.7.124:18445/admin` 使用现有预览访问用户名/密码。仅在设置 `SENREN_FILES_DIR` 且配置访问凭据时启用；服务进程只写 `/var/lib/senren-web/test-resources`，原版 `/opt/senren-web/game/base` 保持只读。测试文件覆盖层随部署保留，不影响18444。

支持多文件上传（单个4 GiB、流式写入、预留512 MiB磁盘）、搜索、下载、重命名、删除、恢复原版及覆盖版本恢复。文本编辑上限2 MiB，支持UTF-8、UTF-8 BOM、UTF-16 BOM及GB18030，编码不匹配时不保存。并发修改使用版本检查，冲突返回409；上传中断不发布半文件。

后台使用原私有Basic凭据及内存CSRF令牌，不开放注册；文件路径、类型及符号链接受限，不管理操作系统配置、密钥、存档、EXE/DLL或成人资源。历史版本保留在独立状态目录，不自动清理；资源变更后重新打开游戏，不保证任意Windows补丁兼容。

验证：`python3 -m unittest discover -s tests -v`；浏览器验证上传、中文编辑、备份列表及桌面/手机布局。发布脚本额外通过真实HTTPS验证测试端口上传、读取、撤销和匿名拒绝。完整游戏剧情兼容性仍另行验收。

## 压缩包部署及性能更新

测试后台可上传ZIP/7z（压缩包按服务器可用空间检查、展开2 GiB、3000个文件），保留目录结构。先解压校验并显示文件/覆盖清单，再由用户确认整体发布。拒绝路径穿越、链接、加密、重名、EXE/DLL及不支持资源；整包校验失败不修改游戏文件，确认时重新检查版本避免覆盖并发修改。使用系统libarchive读流，不执行包内程序。普通材质文件是否能替换XP3中的资源仍取决于原游戏查找路径，不能承诺任意Windows补丁兼容。

性能更新最初关闭原引擎`outputlog`启动画面日志；用户于2026-10-27要求恢复，当前默认开启，并可从顶部“画面日志”切换后重启。保留错误对话框；提供硬件加速/兼容模式切换，默认OpenGL、目标30fps。资源Range加入256 MiB浏览器磁盘缓存，单项32 MiB，使用服务器资源版本隔离；更换资源后新启动不复用旧块。服务器HTTP/1.1复用连接，PROPFIND消费请求体；引擎版本资源允许私有浏览器缓存。缓存占用浏览器空间，不改变存档。

测试：20项Python文件/HTTP/ZIP/7z验证，Node缓存重用/资源版本失效/跨域跳过验证。软件GPU的浏览器可进入主菜单，但不等同于手机实际帧率或完整剧情验收。

## 画面日志和加载进度

`/play` 默认传入 `startupLog=1`，原生启动画面日志恢复开启；`startupLog=0` 可关闭。顶部可切换日志、收起或展开加载进度。按响应实际读取字节与Content-Length计算当前引擎/资源区段的百分比；总量未知或内部初始化时使用不定进度，不显示虚构的整体游戏百分比。缓存命中单独统计，后台消息校验来源和iframe身份。没有修改游戏存档。

检查：Node流读取验证实际20%/100%、未知总量、HTTP错误和缓存状态；浏览器核对原引擎outputlog为1、加载消息和手机/桌面进度面板。

## 通用资源覆盖兼容层

测试端口支持 `unencrypted/<原资源路径>` 与 `unencrypted.xp3` 的常规脚本、图片（含PIMG）、音频和字体覆盖。原版XP3按只读视图提供给引擎，不重写或复制整份游戏；明文替换条目使用上游Xp3Pack的hash=0约定。后端显示已映射、未匹配和解析错误，映射不等于运行验收。Windows DLL、注入、自动提取及任意未来补丁不能据此宣称完整兼容。范围、限制与测试边界见 [docs/DLL_COMPATIBILITY.md](docs/DLL_COMPATIBILITY.md)。

## 启动预缓存、绘制帧率及只读鉴赏

默认启动预缓存目标为256 MiB（可选0/16/32/64/128 MiB），只准备XP3头部/索引及初始化、字体等优先资源，不下载整个游戏。缓存与运行时共享1 MiB分块，磁盘分块缓存上限256 MiB，后续按需读取并淘汰旧块；引擎脚本/WASM仍使用独立浏览器缓存。预缓存中断可复用已完成块，也可点击立即进入。区段、长度、If-Match版本和启动资源版本复核通过后启动。缓存容量不含存档及浏览器自身HTTP缓存。

顶部“绘制FPS”按主canvas默认帧缓冲实际绘制/清屏的帧统计，不使用屏幕刷新率或纯requestAnimationFrame次数冒充游戏帧率；隐藏页面显示暂停。

启动选择普通模式，或导入用户自己的已解锁CG存档ZIP进行只读鉴赏。ZIP最多32 MiB、展开64 MiB、1000个文件，在浏览器内校验路径、展开长度和CRC；支持savedata目录（可有外层目录）及常见平铺ksd/cfu存档。资源缓存可提前进行，但选择模式并导入完成前不启动游戏。鉴赏模式不打开正常存档数据库，屏蔽持久存档导入、导出、删除和写入；所需临时运行写入仅存在内存，关闭丢弃，不提供云存档同步。没有修改或生成CG解锁标志，实际解锁状态取决于用户存档及游戏版本。

已移除ZIP/7z压缩包512 MiB的固定上传限制；仍需保留服务器512 MiB运行空间，解压总量2 GiB及3000项限制继续明确显示。

验证：28项Python文件/HTTP/档案/版本/预缓存检查；Node缓存复用与取消、真实绘制计数、传输进度、存档CRC/路径检查。浏览器原生WASM测试确认预缓存复用（重启零次重复游戏区段请求）、实际绘制FPS，以及只读导入可见、正常存档字节保持不变、持久导出被拒绝。测试存档为自制夹具，不代表用户全CG存档已通过游戏鉴赏验收。

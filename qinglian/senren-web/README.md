# 千恋＊万花 WebAssembly 私有预览

生产预览18444，开发测试18445。用户已授权先发布预览，后续改动仅更新测试端口；完整剧情、中文和账号云存档的验证状态需据实际记录更新，不能把菜单截图当作通关验收。

本项目使用 KrKr2 Web 的公开发布构建（源提交2028cbccaa91498bd36f270d349ae711d0e8fed3）。原引擎版权与第三方声明在 engine/LICENSE.upstream.txt。浏览器外层移除统计请求、固定持久存档空间，16:9游戏视口适配手机横屏；支持JSPI的新版Chromium与可信HTTPS是运行条件。

游戏本体、成人资源、原生游戏可执行文件、用户提供的分享地址、下载签名、密码和存档均不进入Git。部署输入使用服务器专用RSA公钥/AES-GCM加密；站点为独立系统用户、独立服务、独立目录，不改变现有轻连和远控服务。两个端口当前使用独立私有访问凭据，凭据由服务器生成，仅私有交付。

资源转换只改XP3索引名称，保留数据段，算法布局参考MIT许可的GARbro YuzCrypt.cs/ArcXP3.cs。兼容脚本来源zeas2/Kirikiroid2_patch，仅用于基础游戏格式和图形兼容，不加载额外成人资源。

首次部署先生成传输公钥，再加入加密资源清单触发准备资源和启动服务。原RAR是恢复源；CPU/磁盘准备完成后才启动端口。后续更新只重启测试服务，发布预览指针保持不变。

账号和云存档模块尚在开发，不属于当前预览版已完成功能。

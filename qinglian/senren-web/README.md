# 千恋＊万花 WebAssembly 私有预览

生产预览18444，开发测试18445。用户已授权先发布预览，后续改动仅更新测试端口；完整剧情、中文和账号云存档的验证状态需据实际记录更新，不能把菜单截图当作通关验收。

本项目使用 KrKr2 Web 的公开发布构建（源提交2028cbccaa91498bd36f270d349ae711d0e8fed3）。原引擎版权与第三方声明在 engine/LICENSE.upstream.txt。浏览器外层移除统计请求、固定持久存档空间，16:9游戏视口适配手机横屏；支持JSPI的新版Chromium与可信HTTPS是运行条件。

游戏本体、成人资源、原生游戏可执行文件、用户提供的分享地址、下载签名、密码和存档均不进入Git。部署输入使用服务器专用RSA公钥/AES-GCM加密；站点为独立系统用户、独立服务、独立目录，不改变现有轻连和远控服务。两个端口当前使用独立私有访问凭据，凭据由服务器生成，仅私有交付。

资源转换只改XP3索引名称，保留数据段，算法布局参考MIT许可的GARbro YuzCrypt.cs/ArcXP3.cs。兼容脚本来源zeas2/Kirikiroid2_patch，仅用于基础游戏格式和图形兼容，不加载额外成人资源。

首次部署先生成传输公钥，再加入加密资源清单触发准备资源和启动服务。原RAR是恢复源；CPU/磁盘准备完成后才启动端口。后续更新只重启测试服务，发布预览指针保持不变。

账号和云存档模块尚在开发，不属于当前预览版已完成功能。

## 文件管理后台（测试端口）

`https://107.150.7.124:18445/admin` 使用现有预览访问用户名/密码。仅在设置 `SENREN_FILES_DIR` 且配置访问凭据时启用；服务进程只写 `/var/lib/senren-web/test-resources`，原版 `/opt/senren-web/game/base` 保持只读。测试文件覆盖层随部署保留，不影响18444。

支持多文件上传（单个4 GiB、流式写入、预留512 MiB磁盘）、搜索、下载、重命名、删除、恢复原版及覆盖版本恢复。文本编辑上限2 MiB，支持UTF-8、UTF-8 BOM、UTF-16 BOM及GB18030，编码不匹配时不保存。并发修改使用版本检查，冲突返回409；上传中断不发布半文件。

后台使用原私有Basic凭据及内存CSRF令牌，不开放注册；文件路径、类型及符号链接受限，不管理操作系统配置、密钥、存档、EXE/DLL或成人资源。历史版本保留在独立状态目录，不自动清理；资源变更后重新打开游戏，不保证任意Windows补丁兼容。

验证：`python3 -m unittest discover -s tests -v`；浏览器验证上传、中文编辑、备份列表及桌面/手机布局。发布脚本额外通过真实HTTPS验证测试端口上传、读取、撤销和匿名拒绝。完整游戏剧情兼容性仍另行验收。

## 压缩包部署及性能更新

测试后台可上传ZIP/7z（压缩包512 MiB、展开2 GiB、3000个文件），保留目录结构。先解压校验并显示文件/覆盖清单，再由用户确认整体发布。拒绝路径穿越、链接、加密、重名、EXE/DLL及不支持资源；整包校验失败不修改游戏文件，确认时重新检查版本避免覆盖并发修改。使用系统libarchive读流，不执行包内程序。普通材质文件是否能替换XP3中的资源仍取决于原游戏查找路径，不能承诺任意Windows补丁兼容。

性能更新关闭原引擎`outputlog`启动画面日志（该路径每条日志调用限速绘制），保留错误对话框；提供硬件加速/兼容模式切换，默认OpenGL、目标30fps。资源Range加入256 MiB浏览器磁盘缓存，单项32 MiB，使用服务器资源版本隔离；更换资源后新启动不复用旧块。服务器HTTP/1.1复用连接，PROPFIND消费请求体；引擎版本资源允许私有浏览器缓存。缓存占用浏览器空间，不改变存档。

测试：20项Python文件/HTTP/ZIP/7z验证，Node缓存重用/资源版本失效/跨域跳过验证。软件GPU的浏览器可进入主菜单，但不等同于手机实际帧率或完整剧情验收。

新增“ChatGPT → 侧边浏览器直连”：在 TUN 模式下可选自动识别本用户 WindowsApps 安装的 Codex/ChatGPT Chromium 网络服务 PID。普通 HTTP/HTTPS 网页使用物理网卡直连，ChatGPT/OpenAI 域名、ECH 和未知流量保留代理，其他程序继续代理。PID 随进程重启自动重新识别，不修改或记录网页内容。

默认关闭。开启后重新连接，正常从开始菜单打开 Codex；若曾显式带代理启动，请先完全退出后重新打开。连接期间暂时关闭本用户系统代理/PAC，由 TUN 接管；断开或退出恢复原值。“恢复全部代理”立即关闭已识别的直连连接，新连接恢复代理，不需要重启整个 VPN。浏览器 QUIC 回退到 TCP，以便读取未加密的目标主机名；不解密 HTTPS、不安装证书。

安装版和免安装版均可从面板下载程序更新，需先断开 VPN 并确认重启；保留账号、设置、原节点和配额。Windows PID/首包路由仅本机处理，不上传浏览器 PID、域名或网页内容。程序主要由 OpenAI Codex（AI）依维护者需求开发；第三方组件保留原作者及许可证。

包含 Windows 原生 socket PID/命令行识别、隔离 TUN 下指定 PID 直连、不同 PID 代理、OpenAI 域名代理和恢复代理检查，以及既有原生协议、GUI、打包更新、安装/卸载验证。它们不等于在用户本机 Codex、所有网页协议或中国移动现场完成验收。

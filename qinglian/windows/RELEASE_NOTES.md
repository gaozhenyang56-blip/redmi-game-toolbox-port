轻连 Windows 1.0.0-preview8

新增可选“ChatGPT → 侧边浏览器直连”：浏览器原生 PAC 将 OpenAI 服务保留代理，普通网页直连；TUN 自动识别对应网络服务 PID、用户、WindowsApps 安装路径和父进程的本地 PAC 启动参数。默认全部代理，PAC 已加载且身份匹配后才放行网页，不使用固定 PID，不把所有 ChatGPT.exe 放行。

默认关闭。开启 TUN 和该功能后重新连接，再完全退出 Codex，选择其 exe，使用“为 TUN 浏览器直连启动”。启动只为该实例应用固定 loopback PAC 并关闭 QUIC；保留 ECH、HTTPS 校验和沙箱。不解密 TLS、不读取网页首包、不记录或上传浏览历史。

开启时暂时关闭本用户系统代理/PAC，由 TUN 接管；断开、退出或崩溃恢复原值。“恢复全部代理”关闭已有直连连接，新连接恢复代理，无需重启 VPN。其他程序、未匹配进程和其他 UDP 仍代理。

安装版和免安装版均支持原面板程序更新，需断开 VPN 并确认重启，保留账号、设置、原节点和配额。代码主要由 OpenAI Codex（AI）依维护者需求开发，第三方组件保留原作者及许可证。

验证包含 Windows socket PID/命令行/父进程识别、真实 JavaScript PAC 域名规则、隔离 TUN 下指定 PID 直连/其他 PID 代理/恢复代理，以及既有协议、GUI、更新、安装/卸载。它们不代表已在用户本机 Codex 或所有网页中完成现场验收。

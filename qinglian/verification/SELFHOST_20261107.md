# 三端可选轻连面板与独立开源工程（2026-11-07 UTC）

用户明确改为三端可替换对应轻连面板服务器，不是通用节点/订阅导入，并要求独立 GitHub 仓库。

实现统一 schema=1/kind=qinglian-server 配置：HTTPS profile 入口、64位客户端接入码、可选专用公开CA和CDN备用入口。三端“关于→面板服务器”导入，先断开，保存后退出并重新打开；可恢复内置。现有发行版内置服务器不变。账号/导出重试按服务器隔离，内置服务器保留旧 account.json/pending-export.json 和Android旧偏好命名；切换中已有Api实例不改变URL/凭据。Android更改持久化与退出在同一锁内，后台导入有大小限制，CA验证结果按文件内容缓存；新配置不跟随远端重定向、不导入节点URL。

Ubuntu隔离核心/代理守护 -I 显式加载随程序安装的 server_config，避免导入失败；Windows打包同一模块。TUN只允许与面板相同的原始公网IPv4，固定助手仅新增一个校验过的公网IPv4直达豁免；Windows保留SID/父进程身份/心跳及程序哈希，Linux保留polkit/固定程序/路由清理。无任意命令、文件路径或路由输入。Android更新签名检查改为与已安装应用一致，支持其他维护者自己的签名，并继续拒绝异签名更新；本次23沿用原私钥。

selfhost/build_panel.py 从精确上游构建并校验原生组件SHA；install.py只允许全新amd64/systemd服务器，拒绝覆盖旧面板，交互设置强密码，生成独立CA/叶证书/接入码/默认父节点及三服务。支持域名及现成有效证书。管理HTTP仅127.0.0.1。export_server.py导出不含管理/节点/私钥的客户端配置；scripts/embed_server.py为三端生成五个私有API资产。自托管文档和全新源码导出工具、无私有凭据的公开CI模板已加入。

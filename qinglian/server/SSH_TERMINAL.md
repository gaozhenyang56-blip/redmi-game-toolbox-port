# x-ui 网页 SSH 终端

入口：https://gaozy.tech/xui/qinglian/ssh 。也可从面板侧栏“SSH终端”进入。先登录原面板管理员，再填写服务器SSH用户名和密码，点击连接。支持键盘、粘贴、调整终端大小和主动断开；仅连接当前服务器本机SSH（127.0.0.1:22），无需在Windows客户端配置。

## 权限与连接

仅qinglian.json配置的ownerId面板会话可用，App只读token和其他面板用户不可用。必须HTTPS及同源WSS；校验TLS和本机root拥有的SSH主机公钥文件，不使用不校验主机密钥的回调。密码只用于当前连接，连接后清空输入，不写入本地存储、Git、配置或日志。面板不保存终端会话记录；系统SSH认证日志及shell自身历史仍按服务器配置工作。

最多2条活动/待认证连接，每分钟最多8次尝试；15分钟无输入或总连接1小时后断开。终端资产随面板本地提供，无外部脚本CDN依赖。SSH账户实际系统权限照常生效，root会话具有管理员权限。

## 回滚

服务器旧二进制保存在 `/usr/local/x-ui/x-ui.before-ssh-<旧SHA256前12位>`。需先根据该次部署元数据核对完整SHA256，停止x-ui后将该备份原子替换 `/usr/local/x-ui/x-ui` 并启动x-ui；不要覆盖数据库、qinglian.json、证书、节点文件或流量记录。部署脚本ssh_upgrade.py包含相同校验/停止/原子替换/启动逻辑，公网检查失败自动调用。回滚后检查API、原登录与节点；不要把旧版面板无法显示SSH入口误认为VPN节点丢失。

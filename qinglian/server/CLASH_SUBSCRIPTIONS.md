# Clash 订阅

本功能由 OpenAI Codex（AI）依维护者需求开发；上游 x-ui、Clash、Mihomo 保留各自作者及许可证。

在 x-ui 的“入站列表”点击 **Clash 订阅**，会为当前可用节点生成链接和本地二维码。每个节点的“操作 → Clash 订阅”只包含该节点。也可在“轻连 App → 节点管理”进入页面，勾选多个节点、设置名称及配置类型，再生成。

| 配置 | 协议 |
| --- | --- |
| 传统 Clash | VMess、Shadowsocks、TCP TLS Trojan |
| Mihomo / Clash Meta | 上述协议，以及 VLESS、WebSocket Trojan、所选入站绑定的可选 HY2 |

传统 Clash 内核本身不支持 VLESS / HY2，因此不能让所有旧客户端使用所有协议。配置对不支持的协议、Reality/XTLS、SS2022、插件或传输明确列出排除原因，不把它们伪装成可用节点。包含多个客户端的入站按客户端分别生成唯一名称。

复制链接到客户端的“从 URL 导入”，或用支持订阅扫码的客户端扫描。可下载 YAML 或保存二维码 PNG。链接完整内容只在创建时显示；遗失后可撤销并重新生成。页面不会调用第三方二维码网站。

链接随刷新同步节点参数，仅包含创建时勾选的入站，不会自动扩大到后来新增的入站。每次拉取都会检查所属用户、启用、到期及剩余额度；全部失效时返回 503，不生成直连兜底配置。生成订阅不修改节点、密码或额度。规则默认通过“节点选择”代理组，用户可在组内选 DIRECT。

需配置可验证的 HTTPS 面板域名。写操作仅允许面板 owner 的 HTTPS 同源会话；App token 无权管理订阅。随机链接令牌只以 SHA-256 摘要保存，绑定 owner 和所选入站，最多 64 个有效链接。Gin 日志中在 logger 之前移除 token 查询参数；配置和响应禁用缓存，不使用外部订阅转换服务。订阅 URL 本身具有所选节点的连接信息读取权限，请私下分发。

撤销立即停止该链接的配置下载，但不能撤回已下载的节点凭据；彻底禁止连接须在入站列表停用节点或更改凭据。其他订阅、App 和原节点不受撤销影响。

HY2 的专用公开 CA 只加入 Mihomo 的 `tls.custom-certifactes` 信任配置，不修改操作系统信任，不关闭证书验证；传统 Clash 不导出这类 HY2。API 私有证书的其他节点不冒充公共证书节点。

验证包含 Go 权限/范围/停用/额度/撤销/令牌日志检查、YAML 严格解析、传统 Clash v1.18.0 与 Mihomo v1.19.16 实际配置检查、Chromium JSON 请求/二维码内容/移动排版。部署时另外使用真实 HTTPS 面板创建临时链接、匿名拉取、实际 Mihomo 加载、撤销并确认 404；不打印生产链接或配置。这不代表所有第三方客户端版本均已实机验收。

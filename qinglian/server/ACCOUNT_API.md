# 账号、主连接和节点导出（v12）

App 在连接页“账号 / 节点导出”中注册或登录，自定义用户名（3..32字符，不含空白）和密码（8..72 UTF-8字节）。密码仅存 bcrypt cost12 摘要；设备会话凭据随机生成，服务器只存 SHA256 摘要，90天有效。同一账号支持多设备登录，额度与用量合并；同一设备仅可注册一个账号。Android ID 经应用范围 SHA256 后用于绑定，不是认证凭据，也不是不可伪造的硬件证明。恢复出厂设置等可能改变该标识。

注册和登录必须明确同意 `domains-permanent-v1` 告知：服务器永久保存该账号主连接与导出节点的连接域名和时间，管理员及本人可查看，包含后台请求；不记录 HTTPS 路径、查询、内容，不实施 HTTPS 解密。拒绝则不启用账号节点。历史无自动删除任务；永久保存仍受存储和备份完整性影响。原有共享节点未添加域名采集，不追溯或伪造此前各用户用量。

## 主连接

App 登录后获取账号独立凭据，同一账号多台设备共用账号节点。兼容协议跟随管理员在原面板选择的 VMess / VLESS / Trojan / Shadowsocks；独立监听端口和 TLS 由本服务生成，使用原专用 API CA。HY2 仍受面板原加速开关与绑定控制，兼容与加速均计入该账号。原节点配置、客户端、计数与旧版 App 继续保留。

主连接用量累计到账号，同时增加所选原面板入站的配额计数，遵守其启用、总额和到期设置；不扣每周导出额度。账号节点租约180秒，App 连接期间约15秒刷新，停止刷新后关闭进程。更换面板选择时旧节点停止，App 需重连。SQLite 的常规事务合并两侧计数；突然断电在跨数据库/WAL场景下不保证严格原子持久化，最后采样窗口也可能少量丢失或超额，不能作为零误差计费系统。

## 导出

每账号每周 256 GiB（256×1024³字节），UTC 周一00:00重置。创建时按申请额度预留，撤销、未使用或错误不返还；每条创建后7天失效，耗尽提前停止。旧记录与累计用量保留；周重置不延长旧节点有效期。

五种可选协议：VMess、VLESS、Trojan、Shadowsocks AEAD、Hysteria2。可填写备注（App最多64字符，API最多192 UTF-8字节且拒绝控制字符），名称写入服务端、App和面板列表、URI名称、ZIP文件名；未填使用默认名称。文件名中的路径/控制字符被替换，包内仅含该导出节点、公开CA、分享链接和客户端配置，没有服务端或签名私钥。

VMess/VLESS/Trojan 使用可验证 TLS，SS 使用 AEAD，HY2 使用可验证 QUIC TLS。由于使用专用 CA，外部客户端通常需要 ZIP 内 CA 和配置，单独分享 URI 不一定足够；不得关闭证书验证。导出端口范围22000..23999 TCP/UDP。主连接不通过导出列表公开配置包。

资源上限（含主连接）：每账号8个、全服务16个同时有效节点；主兼容与加速各占一个。到期/撤销停止独立原生进程，覆盖已有长连接。端口不复用历史记录中已分配端口，以避免过期凭据意外命中新节点；端口池耗尽需管理员规划迁移，不能静默重用。服务内存上限768MiB，超出资源需扩容，不能据服务器1Gbps接口推定手机跨境吞吐。

## HTTPS API

与现有 App API 共用严格验证 CA 的 HTTPS 主机和基路径，前缀 `/api/v1/exports/`。不要使用 HTTP 或在公开日志记录凭据。公开注册/登录也必须带 `X-Qinglian-Device: <64hex摘要>`。

| 方法 / 相对路径 | 含义 |
|---|---|
| POST register | username、password、historyConsent；注册并返回 token、userId |
| POST login | 同上；只替换同设备会话，保留其他设备 |
| GET quota | 周额度、重置时间、主连接＋导出累计上传/下载 |
| POST profile | 主连接租约与独立配置；ready 为 false 时稍后重试 |
| POST nodes | requestId(UUID)、protocol、sizeMiB、remark(可选) |
| GET nodes | 仅本人导出节点；有效且 active 时含客户端 profile |
| POST nodes/:id/revoke | 撤销本人节点，不退额度 |
| GET history | 本人永久域名记录，最多200条；before 游标加载更早记录 |

除注册/登录外，还需 `Authorization: Bearer <64hex会话>`。设备摘要不能代替凭据。`requestId` 重试幂等；更改协议/大小/备注后复用原 key 返回409。修改设备或使用另一用户 token 不会获得原用户节点/历史。绑定旧管理员 API key 的兼容 `/bind` 接口也要求同样明确告知。

面板登录管理员可创建自定义账号、撤销用户、查看所有账号累计流量、查看各节点及按用户筛选永久域名记录。创建账号不代表已同意采集；必须本人在 App 登录时同意，服务才能开启。现有面板写入同源/CSRF检查继续保留。

## 运维与限制

`qinglian-exports.service` 监督隔离的原 Xray1.4.2/Hysteria2.13.0进程；管理/认证只监听127.0.0.1:11456，管理需随机令牌。数据库/计数/历史写入故障时停止通道；历史日志仅在内存/FIFO中提取域名，不把原始日志持久化。停用账号会停止全部节点。数据在现有私有 statePath 数据库中，备份工作流包含一致性快照与新服务配置。

域名来自代理目标及 HTTP/TLS/QUIC 元数据嗅探；ECH、只有IP且无可识别域名、协议不支持嗅探等场景可能无法识别。因此展示为“连接域名观察记录”，不能声称完整浏览历史或精确网页访问次数。30秒桶合并同节点同域名观察；高流量时原生日志也可能丢弃观察，流量统计与域名观察次数不是同一计数。

手动工作流 `qinglian-server-upgrade.yml` 先备份/构建并升级面板，随后运行 `qinglian-exports-deploy.yml`，后者再备份、安装服务并做公网五协议及主连接检查，测试账户在停止后清除。回滚原服务时先停止新单元，避免旧面板缺失续租入口；原节点不依赖新单元。

# 账号、主连接、访客与节点导出（v17）

App 从连接页“账号 / 节点导出”进入独立账号页面注册或登录，自定义用户名（3..32字符，不含空白）和密码（8..72 UTF-8字节）。密码仅存 bcrypt cost12 摘要；设备会话凭据随机生成，服务器只存 SHA256 摘要，90天有效。同一账号支持多设备登录，额度与用量合并；同一设备仅可注册一个账号。Android ID 经应用范围 SHA256 后用于绑定，不是认证凭据，也不是不可伪造的硬件证明。恢复出厂设置等可能改变该标识。

注册和登录必须明确同意 `domains-permanent-v1` 告知：服务器永久保存该账号主连接与导出节点的连接域名和时间，管理员及本人可查看，包含后台请求；不记录 HTTPS 路径、查询、内容，不实施 HTTPS 解密。拒绝则不启用账号节点。历史无自动删除任务；永久保存仍受存储和备份完整性影响。原有共享节点未添加域名采集，不追溯或伪造此前各用户用量。

## 主连接

App 登录后获取账号独立凭据，同一账号多台设备共用账号节点。兼容协议跟随管理员在原面板选择的 VMess / VLESS / Trojan / Shadowsocks；独立监听端口和 TLS 由本服务生成，使用原专用 API CA。HY2 仍受面板原加速开关与绑定控制，兼容与加速均计入该账号。原节点配置、客户端、计数与旧版 App 继续保留。

主连接用量累计到账号，同时增加所选原面板入站的配额计数，遵守其启用、总额和到期设置；不扣每周导出额度。账号节点租约180秒，App 连接期间约15秒刷新，停止刷新后关闭进程。更换面板选择时旧节点停止，App 需重连。SQLite 的常规事务合并两侧计数；突然断电在跨数据库/WAL场景下不保证严格原子持久化，最后采样窗口也可能少量丢失或超额，不能作为零误差计费系统。

## 导出

每账号每周 256 GiB（256×1024³字节），UTC 周一00:00重置。创建时按申请额度预留，撤销、未使用或错误不返还；每条创建后7天失效，耗尽提前停止。旧记录与累计用量保留；周重置不延长旧节点有效期。

五种可选协议：VMess、VLESS、Trojan、Shadowsocks AEAD、Hysteria2。可填写备注（App最多64字符，API最多192 UTF-8字节且拒绝控制字符），名称写入服务端、App和面板列表、URI名称、ZIP文件名；未填使用默认名称。文件名中的路径/控制字符被替换，包内仅含该导出节点、公开CA、分享链接和客户端配置，没有服务端或签名私钥。

VMess/VLESS/Trojan 使用可验证 TLS，SS 使用 AEAD，HY2 使用可验证 QUIC TLS。由于使用专用 CA，外部客户端通常需要 ZIP 内 CA 和配置，单独分享 URI 不一定足够；不得关闭证书验证。导出端口范围22000..23999 TCP/UDP。主连接不通过导出列表公开配置包。

资源上限（含主连接）：每账号8个、全服务16个同时有效节点；主兼容与加速各占一个。到期/撤销停止独立原生进程，覆盖已有长连接。普通账号节点端口不复用历史记录；仅已停用访客端口可在真实端口空闲且使用新随机凭据时复用；端口池耗尽需管理员规划迁移，不能静默重用。服务内存上限768MiB，超出资源需扩容，不能据服务器1Gbps接口推定手机跨境吞吐。

## HTTPS API

与现有 App API 共用严格验证 CA 的 HTTPS 主机和基路径，前缀 `/api/v1/exports/`。不要使用 HTTP 或在公开日志记录凭据。公开注册/登录也必须带 `X-Qinglian-Device: <64hex摘要>`。

| 方法 / 相对路径 | 含义 |
|---|---|
| POST register | username、password、historyConsent；注册并返回 token、userId |
| POST login | 同上；只替换同设备会话，保留其他设备 |
| GET quota | 周额度、重置时间、主连接＋导出累计上传/下载 |
| POST profile | 主连接租约与独立配置；ready 为 false 时稍后重试 |
| POST nodes | requestId(UUID)、protocol、sizeMiB、remark(可选) |
| GET nodes | 仅本人导出节点；有效且 active 时含客户端 profile |
| POST nodes/:id/revoke | 撤销本人节点，不退额度 |
| GET history | 本人永久域名记录，最多200条；before 游标加载更早记录 |

除注册/登录外，还需 `Authorization: Bearer <64hex会话>`。设备摘要不能代替凭据。`requestId` 重试幂等；更改协议/大小/备注后复用原 key 返回409。修改设备或使用另一用户 token 不会获得原用户节点/历史。绑定旧管理员 API key 的兼容 `/bind` 接口也要求同样明确告知。

面板登录管理员可创建自定义账号、撤销用户、查看所有账号累计流量、查看各节点及按用户筛选永久域名记录。创建账号不代表已同意采集；必须本人在 App 登录时同意，服务才能开启。现有面板写入同源/CSRF检查继续保留。

## 运维与限制

`qinglian-exports.service` 监督隔离的原 Xray1.4.2/Hysteria2.13.0进程；管理/认证只监听127.0.0.1:11456，管理需随机令牌。数据库/计数/历史写入故障时停止通道；历史日志仅在内存/FIFO中提取域名，不把原始日志持久化。停用账号会停止全部节点。数据在现有私有 statePath 数据库中，备份工作流包含一致性快照与新服务配置。

域名来自代理目标及 HTTP/TLS/QUIC 元数据嗅探；ECH、只有IP且无可识别域名、协议不支持嗅探等场景可能无法识别。因此展示为“连接域名观察记录”，不能声称完整浏览历史或精确网页访问次数。30秒桶合并同节点同域名观察；高流量时原生日志也可能丢弃观察，流量统计与域名观察次数不是同一计数。

手动工作流 `qinglian-server-upgrade.yml` 先备份/构建并升级面板，随后运行 `qinglian-exports-deploy.yml`，后者再备份、安装服务并做公网五协议及主连接检查，测试账户在停止后清除。回滚原服务时先停止新单元，避免旧面板缺失续租入口；原节点不依赖新单元。

## 免登录访客（v13）

访客独立于注册账号，不占Android ID的注册次数。明确告知设备摘要/配额后即可直接连接；不采集访客域名、不要求账号域名同意。每次手动连接共64GiB（64×1024³），不是每日或每设备终身额度；自动网络恢复、切换底层网络和续租保持同一会话。代理兼容/HY2所有kind=guest节点累计合并判限，原入站配额/启用/到期及资源上限仍生效，国内直连不计入服务端代理流量。原共享节点及旧App不变。

所有接口仅HTTPS。POST `/api/v1/guest/start` 使用现有App引导令牌和设备摘要，提交随机UUID requestId及随机64hex sessionKey；服务器仅存其SHA256。相同请求与密钥幂等，旧会话不得复活。新手动会话会停用同设备旧访客及其节点。后续凭sessionKey与设备摘要访问POST `/api/v1/guest/profile`、GET `/api/v1/guest/quota`、POST `/api/v1/guest/stop`。不能访问账号导出或历史。配额耗尽不自动创建新会话；用户手动再次连接才能重新获得限额。

访客节点沿用180秒租约、15秒续租；服务端监督进程按所有访客节点累计字节检查64GiB，同时关闭兼容和HY2。采样窗口及缓冲仍有少量超额可能，不是零误差计费。访客不混入注册账号表格，但节点页标记用途与共享额度。Android ID摘要仅绑定设备，不是不可伪造硬件身份。

POST `/api/v1/exports/logout` 撤销当前设备会话；其他设备会话不受影响。退出前App要求停止VPN，账号页状态和错误在登录/已登录区均可见。

面板路由：`/xui/qinglian` 概览，`/xui/qinglian/manage/{accounts,nodes,history,updates,devices}`。原API路径、登录、同源检查保持；不能把页面路径与API混用。

## 速度实验室：设备隔离HY2（v14）

主连接/访客profile可提交 `{"labHy2":true}`，只接受布尔值，设备摘要仍必须通过原会话认证。仅HY2生成独立request key（kind/parent/protocol加lab及设备摘要），兼容节点不变；普通请求仍复用原账号节点，不能改其他设备的实验或保守参数。响应labHy2确认生效、acceleration.node.hy2Performance=aggressive-v1，独立revision/凭据/端口。App只在加速模式请求，未确认则拒绝把普通模式误报为实验成功。

账号监督引擎只对kind=main/guest且服务器保存标记匹配的HY2开启BBR aggressive、ignoreClientBandwidth=true和8/32MiB流窗口、16/64MiB连接窗口。原共享HY2、普通节点、独立导出节点不改；未修改系统级sysctl或全部用户带宽。现有每账号8条/全局16条及768MiB限制仍在，资源满返回不可用，不挤占/删除已有节点来创建实验节点。物理资源与带宽仍共享，不能承诺完全无相互竞争。

同设备labHy2=false请求恢复普通HY2并将自己的旧实验租约过期；其他设备节点不受此更新影响。自动恢复/15秒续租复用原实验key，180秒失联停止。实验流量仍计入账号及原父配额；访客实验与普通访客行合并64GiB，不重置预算且不记录域名。没有因开实验解除到期/总量、TLS校验、管理端口loopback或私网出站限制。

## 服务器链路测速（v15）

GET `/api/v1/exports/speed?bytes=N` 使用原账号设备会话，GET `/api/v1/guest/speed?bytes=N` 使用当前访客会话；均要求HTTPS及X-Qinglian-Device。只允许真实r.RemoteAddr为loopback或配置serverAddress（当前为固定公网IP）的请求，直接手机来源403，忽略X-Forwarded-For。App必须显式经当前核心HTTP代理，TLS保留原专用CA/主机名验证。由现有VPN节点计量，接口本身不另加重复计数；原父配额、账号统计和64GiB访客合计仍执行。

每请求1..33554432字节，200 application/octet-stream、精确Content-Length、X-Qinglian-Speed: server-v1、Cache-Control:no-store、Content-Encoding:identity。固定32KiB缓冲重复写出，TLS/VPN密文实际传输，无HTTP压缩；不是把整个N字节存入内存。取消即停止，最多4路/账号、8路/服务，超出429 Retry-After:2。无有效令牌401、非法长度400、未从VPN服务器来源403。App大小1..2048MiB通过多段请求完成。

此源测手机到服务器VPN链路，排除服务器到Cloudflare的外部下载瓶颈；Cloudflare仍作为可选外网源。两者不能无标注混合或自动回退至直连。接口不新建节点、不放宽配额、不修改v14激进参数。

## v16高性能默认与兼容合同

v16将高性能移至连接页并设为HY2默认，服务端合同保持v14私有labHy2布尔字段和aggressive-v1标记，不移除、不重命名以兼容旧APK。新App加速+高性能发送true；兼容通道或明确保守发送false。服务端仍只在true时分配该设备隔离高性能节点，旧APK和其他设备不被全局改变。native窗口、BBR、配额和资源上限不变。

App每次手动连接固化通道/性能，账号和访客的profile请求使用同一options；后台续租与自动恢复不读取新界面偏好。界面选择高性能/保守或兼容/加速仅保存下次连接，不能让false续租请求提前过期当前高性能节点。profile网络请求使用独立锁串行化，返回时校验所属Selection；不以类级锁阻塞UI。新App须同时验证响应labHy2和节点标记后认定高性能，保守请求收到高性能标记也拒绝。

## v17 TCP协议对照与多隧道

账号/访客 `POST profile` 可传 `tcpProtocol`：空字符串沿用面板，`vless`或`trojan`请求原服务器主连接worker。其他类型/值400，返回字段`tcpProtocol`回显选择和`transportOptions`能力列表。非空选择须由App同时确认回显和node.protocol；旧服务忽略选项时不可冒充已切换。原parent启用/总额/期限、每账号8个/总16个资源限制、180秒租约、周导出不扣、账号累计与访客合并64GiB继续执行。切换回空选择不旋转或删除原默认凭据，旧App/其他设备保留。

双HY2只在客户端建立两条同凭据QUIC连接，无新增节点或访客会话；HY2原native计量以同一worker/auth汇总，原额度耗尽/到期会同时停用。自动模式仍续租相同TCP协议及高性能选项，即使暂时选TCP也不通过错误labHy2=false请求退休备用节点。

此前更新：
轻连 Ubuntu 1.0.0-preview6，适配 Ubuntu 24.04 amd64 GNOME（含 ubuntu-to-go 分支的系统）。这是独立桌面版。

- 同步 Android v21 连接修复：HY2 首次验证读取预算12秒、总预算15秒；兼容通道读取3秒、总预算8秒。取消/截止会关闭验证套接字，取消不会误报连接失败。连接失败提供固定阶段/HTTP/超时/TLS错误码，不显示原始异常或凭据；仍需严格CA与真实1字节响应确认，未修改服务器HY2参数。
- 域名/CDN连接：安装包可内置固定域名入口，优先使用标准公网HTTPS证书验证的CDN，保留原IP 443/11452入口与独立专用CA，不跟随重定向。原服务器链路测速和TUN节点约束仍固定原服务器，不能把CDN下载当作VPN测速。注册、导出等POST仅在确认尚未发送时切换入口，发送后超时提示结果未确认，避免自动重复执行。
- 界面更新：类似 FlClash 的桌面左侧导航和双栏卡片，延续手机版 Material 3 配色、圆角与玻璃滑块；窄窗口切为底部导航和单栏。连接、测速、分流、关于、ChatGPT、账号六个页面。
- 内置第一版风格的简约模式：传统桌面标签页、下拉框与单栏表单，保留全部功能并持久保存（顶部按钮 / Ctrl+Shift+M）；切换不重建连接、不改变配置或丢失账号输入。兼容 preview1 的设置。
- 本应用内容实时高斯毛玻璃，最多12Hz、低分辨率取样与未变像素复用，隐藏/最小化停止计算；亮色/暗色/跟随系统。页面与滑块动画保留鼠标和键盘操作。
- 共用现有面板：VMess、VLESS、Trojan、Shadowsocks、HY2；加速默认高性能，保守可选；免登录单次64GiB，账号累计用量和五协议节点导出。
- ChatGPT 专用启动附加显式代理与环境变量、关闭QUIC，保留本机OAuth回调；完整退出旧实例后使用。忽略代理的软件可选TUN全局接管（需系统授权，先关闭其他VPN/Clash）。系统代理模式支持大陆/私网绕过规则。
- 连接成功前验证实际代理链路，断开恢复原系统代理/自建路由；服务器链路测速大小可自定义1..2048MiB，显示Mbps。
- 系统用户范围设备应用摘要绑定，正常App重装不重置注册标识；不上传原machine-id。账号域名/时间永久记录需用户明确同意，访客不记录域名。

下载 deb 后，在安装包所在目录执行：

```sh
sudo apt install ./Qinglian-1.0.0-preview6-amd64.deb
qinglian
```

验证包含 Ubuntu24.04 实际安装/卸载、GUI、五协议原生传输及HY2高性能、隔离网络中真实IPv4/IPv6 TUN和清理、现有服务器三个通道各1MiB传输/计量。resolved调用在隔离测试中由记录shim替代；尚未在用户原桌面点击授权、登录其ChatGPT账号或完成长时间稳定性验收。

TUN仅全局；系统代理规则绕大陆，不提供Linux按应用黑白名单。TUN需Ubuntu原生systemd-resolved stub，固定面板同服务器节点；不是断网保护开关。root助手被SIGKILL/系统异常时不保证自动恢复，详见使用说明。安装包内仅含App引导token/公开CA，不含管理员、SSH、用户会话或Android签名材料；引导token与Android一样可提取，服务端权限/配额才是边界。
